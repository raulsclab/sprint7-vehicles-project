# Panel de anuncios de venta de coches (Sprint 7)

Aplicación web interactiva desarrollada con **Streamlit**, **Pandas** y **Plotly Express** para el análisis exploratorio de datos (EDA) del conjunto de datos `vehicles_us.csv`.

## Funcionalidades
- **Histograma interactivo:** Visualización de la distribución del kilometraje (`odometer`) de los vehículos anunciados.
- **Gráfico de dispersión:** Análisis de la relación entre el kilometraje (`odometer`) y el precio (`price`) de los vehículos.
